#  Sales Dashboard using Power BI

##  Project Overview
This project focuses on analyzing sales data to uncover key business insights and support data-driven decision-making. An interactive Power BI dashboard was developed to visualize trends, identify high-performing areas, and detect regions with losses.

##  Problem Statement
Businesses often struggle to understand sales performance across different regions, categories, and time periods.  
This project aims to analyze sales data and provide actionable insights to improve profitability and optimize strategies.

##  Tools & Technologies
- Power BI  
- DAX (Data Analysis Expressions)  
- Power Query (Data Cleaning & Transformation)  

##  Dataset
- Superstore Sales Dataset  
- Contains information on orders, sales, profit, categories, and regions  

##  Dashboard Features
- KPI Cards: Total Sales, Total Profit, Total Orders  
- Sales Analysis by Region  
- Category-wise Profit Analysis  
- Monthly Sales Trend  
- Top 5 Products by Sales  
- Interactive Filters (Region, Category, Date)  

##  Key Insights
- Identified high losses in the West region  
- Technology category generates the highest profit  
- Sales show a peak trend during the end of the year (Q4)  
- Certain products contribute disproportionately to revenue  

##  Outcome
This dashboard helps stakeholders:
- Monitor sales performance in real-time  
- Identify loss-making regions and take corrective actions  
- Optimize product and regional strategies  
- Make data-driven business decisions  


## Future Improvements
- Add forecasting using time-series analysis  
- Implement drill-through pages for deeper insights
